- **Owner**: Mani Kumar
- **Role**: AI-Powered WordPress Designer & Digital Creative
- **Stack**: HTML5, CSS3, JavaScript, Bootstrap 5
- **Design Archetype**: Deep Forest Green (`#294B32`) + Warm Golden Yellow (`#F5B51B`) + Editorial Minimalist White (`#FFFFFF`)

## 🛠 Features & Verification

- **Floating Pill Navigation**: Sticky on scroll with active indicator, smooth scrolling, and mobile drawer menu.
- **Hero Presentation**: Asymmetric layout with yellow circular backdrop, floating skill pills, and trust metrics.
- **Continuous Marquee**: Infinitely looping ticker highlighting core design and AI capabilities.
- **Animated Statistics**: IntersectionObserver-based counter (2+ Years, 50+ Websites, 100+ Social Designs, 200+ AI Videos).
- **Interactive Project Filtering**: Instant category filtering for Websites, UI/UX, Social Media, and AI Content.
- **Dedicated Vertical Video Player**: 9:16 reels portfolio with interactive preview modal.
- **Front-End Form Validation**: Validates name, email format, and message requirements before submission.
- **Accessible & Performance Optimized**: Semantic tags, ARIA attributes, responsive typography, and `prefers-reduced-motion` support.

## 💻 How to Run Locally

You can open `index.html` directly in any modern web browser or run with any standard local HTTP server:

```bash
# Using Python
python3 -m http.server 3000

# Using Node / npx
npx serve .
```
